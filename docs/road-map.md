# Road Map

This is a list of feaures and improvements we plan to work on to make Splitty Test better. We'll try to keep this list updated as often as possible. If you have any suggestions for features or have found any bugs, please use [GitHub issues](https://github.com/SplittyTest/SplittyTest/issues).

## Features

A list of features and improvements we plan on making to Splitty Test.

* **Watchers and Alerts:** Watch a test to get alerts in app and via email when something interesting happens.
* **Variation Builder:** Auto scaffold variations by creating all possible combinations of values for each data property.
